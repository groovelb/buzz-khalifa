# 건축 공정 스테이지 규칙

## 5단계 공정 상세 정의

### Stage 1: Foundation (0% ~ 20%)
**지반 기초 공사**

구현 요소:
- 지반 매트(Mat) - 넓은 직사각형 기초판
- 파일(Piling) - 수직 기둥들이 순차적으로 박히는 애니메이션
- 땅 표면 변화 - 공사 진행에 따른 지면 변형

시각화:
```
[0-10%] 지면 준비 - 평평한 기초 영역 표시
[10-20%] 파일 박기 - 여러 개의 기둥이 아래에서 위로 솟아오름
```

### Stage 2: Core (20% ~ 40%)
**콘크리트 코어 상승**

구현 요소:
- 중앙 육각형/원형 코어 구조물
- 슬립폼 공법 표현 - 아래에서 위로 연속 상승
- 엘리베이터 샤프트 공간

시각화:
```
[20-30%] 코어 하부 형성
[30-40%] 코어가 전체 높이까지 상승
```

### Stage 3: Setbacks (40% ~ 60%)
**나선형 후퇴 구조**

구현 요소:
- Y자형 평면 구조
- 층별 후퇴(Setback) - 위로 갈수록 좁아지는 형태
- 바람 저항 최소화 디자인 표현

시각화:
```
[40-50%] 하부 날개 구조 확장
[50-60%] 상부로 갈수록 후퇴하며 나선형 완성
```

### Stage 4: Cladding (60% ~ 80%)
**커튼월 외벽 설치**

구현 요소:
- 유리 패널 부착 애니메이션
- 반사 효과 (파스텔 블루)
- 층별 순차적 설치

시각화:
```
[60-70%] 하부 외벽 유리 부착
[70-80%] 상부까지 유리 패널 완성
```

### Stage 5: Spire (80% ~ 100%)
**첨탑 및 안테나 설치**

구현 요소:
- 뾰족한 첨탑 구조물
- 안테나/통신 장비
- 최종 조명 효과

시각화:
```
[80-90%] 첨탑 기초부 설치
[90-100%] 안테나 상승 및 완공 효과
```

## 스테이지 전환 규칙

### 부드러운 전환
- 스테이지 경계에서 급격한 변화 금지
- 최소 5% 구간의 페이드/블렌딩 적용
- 이전 스테이지 요소는 유지 (사라지지 않음)

### 누적 표현
```
Stage 1: [Foundation]
Stage 2: [Foundation] + [Core]
Stage 3: [Foundation] + [Core] + [Setbacks]
Stage 4: [Foundation] + [Core] + [Setbacks] + [Cladding]
Stage 5: [Foundation] + [Core] + [Setbacks] + [Cladding] + [Spire]
```

### 스테이지 컴포넌트 인터페이스
```typescript
interface StageProps {
  progress: number;      // 0-1 (전체 스크롤 진행도)
  stageProgress: number; // 0-1 (해당 스테이지 내 진행도)
  isActive: boolean;     // 현재 스테이지 여부
  isComplete: boolean;   // 완료 여부
}
```

## 참조
- 부르즈 할리파 실제 공정 순서 기반
- Y-shape 평면은 바람 저항 최소화 목적
- 후퇴 구조는 27회의 setback으로 구성 (단순화하여 표현)
